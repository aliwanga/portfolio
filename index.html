ACPS-HUB Bookshelf

2026

A free book search tool for students and readers. It searches seven open libraries at once and shows only legally available copies, so finding a book no longer means checking several websites.

  • Search Project Gutenberg, Open Library, Internet Archive, Google Books, Wikibooks, Wikisource and Crossref together
  • Duplicate books merged into one card with a link to every source
  • Access labels: Free to read, Borrow, Preview or Info only
  • My Shelf reading list with Want to read, Reading and Finished, plus CSV and JSON export
  • Sort, language filter (including Kiswahili), subject shortcuts and recent searches
  • Book details with copy-citation button for school work
  • Keeps working if one source fails, with a retry button
  • Light and dark mode, responsive on phones
  • JavaScript
  • REST APIs
  • localStorage
  • Responsive
